# ОБЪЕКТИВ-07

Архив открытых источников (OSINT) в кадре старой камеры: чисто чёрный монитор, fisheye / рыбий глаз, OSD, зерно, scanlines.

Открой `index.html` или подними любой статический сервер из корня репозитория.

Клавиши: `/` захват цели, `0–9` канал, `F` fisheye, `H` помощь.

Только законные исследования. Ссылки ведут на чужие публичные сервисы.

## ОБЪЕКТИВ-07 · DASHBOARD (Arch)

Тот же вид, но с ярлыками установленных приложений вместо OSINT-источников.
Дашборд живёт слоем поверх обоев (Hyprland / Sway, Wayland).

```bash
cd desktop
./install.sh     # пакеты + ~/.local/share/objektiv + команда objektiv
objektiv        # запуск
```

Управление: `/` поиск, стрелки — выбор, `↵` запуск, `S` избранное, `F` объектив,
`R` перескан, `H` помощь, `0–9` канал.

Подробности, конфиг и интеграция с Hyprland/Sway — в [`desktop/README-ARCH.md`](desktop/README-ARCH.md).

Быстрый просмотр оформления без установки: открой `desktop/ui/index.html`
(демо-набор приложений подставится автоматически).
